# 📊 Day 2: Data Analysis with NumPy & Pandas

Welcome to Day 2 of my Data Analysis & Machine Learning learning journey! 🚀

In this section, I explored core concepts of **NumPy** for numerical computations and **Pandas** for data manipulation and analysis using the famous **Titanic Dataset** in the bootcamp.

---

## 📝 Overview
This repository contains my practice notebooks where I applied functions, loops, strings, conditions, data preprocessing, statistical operations, filtering, and indexing techniques using Python's fundamental data science libraries.

---

## 📚 Topics Covered

### 1. NumPy Fundamentals
* **Array Creation & Properties:** Creating 1D & 2D arrays, checking `.shape`, `.ndim`, and `.dtype`.
* **Mathematical & Statistical Functions:** `np.sum()`, `np.mean()`, `np.max()`, `np.min()`, and `np.std()`.
* **Array Operations:** Vectorized operations and scalar multiplication.
* **Indexing & Slicing:** Accessing specific rows, columns, and sub-matrices.

### 2. Pandas & Data Analysis
* **Data Loading:** Reading datasets from CSV files using `pd.read_csv()`.
* **Data Exploration:** Viewing initial rows using `.head()`, checking summary statistics, and data structures.
* **Boolean Masking & Filtering:** Filtering specific criteria (e.g., survival analysis based on gender).
* **Frequency & Proportions:** Using `.value_counts()` and `normalize=True` to calculate counts and percentage distributions.
* **Slicing Ranges:** Locating specific rows/passengers using `.loc[]` and `.iloc[]`.
